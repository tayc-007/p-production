# P.PRODUCTIONS website

A responsive single-page Next.js website using the Pages Router (pages/) and Chakra UI.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Customise

Edit pages/index.js to change the booking URL, pricing, TikTok profile and video IDs.

The logo is stored in public/logo-original.png and public/logo-original.jpeg.
